# 保真模式采用条件性承诺与标记图像优先交付

状态：已确认。

NegLift 保留实用转换作为默认工作流，仅为已记录、已验证的彩色负片相机翻拍原始图像配置提供保真模式；每个配置绑定一个固定采集装置和一个胶片型号。证据缺失或验收未通过时，保真模式可以导出明确标记为未验证的文件；已验证文件必须具有经过阈值评价的色彩与中性重复性、跨帧一致性和逐通道裁切质量保证数据。首个交付格式为十六位标记图像文件：可嵌入的谱系信息写入文件，完整谱系写入配套记录文件。数字底片导出将在其语义和互操作性完成验证前移除。

保真模式只允许已记录的反相、色彩转换、几何变换以及白平衡或曝光保真调整。创意调色、降噪、除尘和生成式修补生成修复派生文件。首版质量保证数值由用户录入或确认，NegLift 负责比较、存档和报告，并以“用户确认的验证”标注，不冒充仪器或软件认证。未验证标记图像文件必须在文件名中加入 `_unverified`，并在界面、文件内元数据和配套记录文件中一致记录状态及缺失或未通过条件。

每个已验证采集配置拥有版本化的验收阈值集，首版由用户通过受控采集会话建立。配置修订版不可变：背光、相机、镜头、倍率、原始图像解码版本或标定发生变化时创建新版本，旧项目继续引用旧版本。整卷保真锁定采集配置、胶片配置、色彩转换、反相锚点和质量保证阈值，只允许逐帧白平衡与曝光保真调整。

建立配置的最低参考物为片基边、已知灰阶和已知色彩目标；缺少任一项的配置只能保存为草稿，不能生成已验证文件。视觉质量保证还要求用户确认显示器色彩配置。配置的本地工作副本可以迁移，但每个导出都会在文件内和配套记录文件中携带配置修订版与阈值集的完整快照。既有实用转换不改变，也不追溯改标；旧版数字底片导出预设自动迁移为十六位标记图像文件，并显示一次迁移说明。

验收阈值集由创建者首次设定；任何变更都属于阈值修订，必须新建配置修订版、重新测量并重新确认。原始采集文件继续由用户在文件系统中保管，配套记录文件仅保存校验值、原路径和可选相对路径。首版的配置仅在本地创建、导入和导出，不提供团队账户、在线共享或审批流。建立配置采用分步向导，依次收集采集条件、参考物确认、测量值与阈值，再复核保存；缺项始终显示为草稿及其原因。视觉质检条件必须记录显示器名称、色彩配置文件标识、系统显示设置、检查日期和操作者确认，但不尝试校准或控制显示器硬件。

胶片以制造商、型号、感光度和可选备注组成的稳定标识绑定配置。每卷开始前必须执行简短检查，并在配置规定的时间或卷数上限后完成完整复测。每个配置还规定逐帧白平衡和曝光调整范围；超出范围时仍允许导出，但自动降为未验证并要求记录原因。若原始采集文件缺失或其校验值失配，也不得继承已验证状态，必须标记为未验证。暂停的仅是未经验证语义的数字底片导出；相机原始数字底片文件仍可作为输入，但只有在其原始数据和采集条件可验证时才能进入保真模式，已渲染或来源不明的同类文件只能使用实用转换或未验证路径。

有新修订版的旧配置标记为已被取代：历史项目仍可引用以复现结果，但新作业默认不再选择它。用户确认的验证必须保存数值、单位、测量日期、操作者、测量方法和参考物标识，并可选回链目标照片或仪器报告的路径和校验值。没有已验证采集配置时，用户仍可进入保真模式试用状态，但界面始终显示未验证，导出也只能产生未验证文件，同时提供建立或选择配置的入口。若已验证保真派生文件继续经过修复处理，修复派生文件必须以其为父版本，保存父文件校验值和处理差异，并支持一键比较；不得覆盖父文件。

保真模式首发为预览功能：在独立、跨配置验证积累完成前，只能使用“用户确认的验证”表述，不宣称软件已独立验证保真。仓库只提交具有明确再分发许可的公开参考测试集和派生测量记录；真实客户底片与完整原始图像只保存校验值和本地测试说明，不提交。第一阶段完成必须同时具备数据模型、分步向导、状态与文件命名、十六位标记图像和谱系记录、旧预设迁移、基础自动测试，并至少有一个受控采集配置通过真实测试集且生成完整质量报告。
