# 保真验收证据不作为使用或预览发布门槛

状态：已确认；修订 ADR-0001 的第一阶段完成门槛，不改变“用户确认的验证”的判定含义。

实用转换与未验证的保真模式试用不要求密度计、测量记录、色彩目标或已验证采集配置。用户可以直接处理本地负片 RAW，输出明确标记为未验证的十六位 TIFF 与谱系记录。缺少证据只限制“用户确认的验证”等可测量的准确性声明，不限制处理和导出。仪器不是产品使用的先决条件。

第一阶段验收以真实负片 RAW 的解码、反相预览、十六位导出、未验证命名、谱系回链和自动测试为准；不得把完整测量报告、用户自备仪器或可再分发的原始底片作为发布前置。若将来要对特定采集配置声明“用户确认的验证”，仍须有适用的参考物、测量方法和阈值结果；这些材料由项目自行寻找可用来源并验证许可，不向普通用户索取仪器或测试资料。没有相应证据时不编造色彩误差或密度准确性数据。

本地用户 RAW 只能用于私有冒烟测试，不因可测试就取得公开分发许可。公开参考资料可以仅链接来源并记录许可和校验值，不强制把大体积原始文件纳入仓库。ADR-0001 中“第一阶段必须有完整质量报告和公开参考测试集”的要求由本决定替代；其已验证状态的证据规则保持不变。
