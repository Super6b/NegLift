# 除尘与「本地小模型」

## 当前实现（无权重、离线）

显示域修补：

| 步骤 | 说明 |
|------|------|
| 孔洞 | 圆形笔刷/自动标记 |
| 初始化 | 外环 Y/Cb/Cr 均值 |
| 扩散 | **仅 Y 通道**各向异性扩散（保边） |
| 色度 | 固定为外环均值，孔内不随 RGB 分通道漂移 |
| 重建 | YCbCr → RGB 写回 |

这样可避免旧版「整块中值」的马赛克感，以及通道分扩散导致的**边缘彩虹纹**。

- **预览**：GPU 近似（环均值 Y/Cb/Cr）  
- **导出/批量**：CPU 扩散（质量基准）；若已加载 ONNX 模型则对孔内再推理一次  

## 本地 ONNX 修补模型（已接入）

1. 在「除尘 → 本地修补模型」点 **选择 ONNX…**，或把 `.onnx` 放入  
   `%APPDATA%/…/neglift-models/`（界面里有「模型目录」）  
2. 兼容常见 **LaMa 风格** 接口：`image` + `mask`，NCHW 或 NHWC，float32 0..1  
3. 加载成功后，**导出与批量**会对每个修复点裁剪邻域推理；单点失败自动回退扩散  
4. 预览仍用快速扩散，避免拖动时卡顿  

### 模型从哪来

- 开源 **LaMa** 的 ONNX 导出（社区有 `lama_fp32.onnx` / `big-lama.onnx` 等，体积约数百 MB）  
- 将文件放到模型目录后重新「选择 ONNX…」加载  
- `onnxruntime-node` 已加入依赖；打包时注意 electron-builder 的 native rebuild  

### 为何仍保留扩散回退

- 模型加载失败 / 单点推理异常时不中断导出  
- 小尘点扩散往往已足够；模型更适合长毛、大片划痕  

## 使用建议

- 小尘点、短毛：笔刷 + 扩散即可  
- 复杂破损：加载 LaMa 后再导出  
- 自动扫描后请检查列表，删掉误报再导出
