# 保真模式公开参考测试集

此目录只接受具有明确再分发许可的真实参考资产及其测量记录；不得提交客户底片、客户原始图像或无法证明许可的样本。

第一阶段的本地验收应为一个受控彩色负片相机翻拍配置保留：源文件校验值、采集配置修订版、片基边、灰阶、色彩目标、色彩与中性重复性、跨帧一致性、逐通道裁切和生成的谱系记录文件。当前仓库尚未附带满足这些条件的真实公开资产，因此保真模式仅作为“用户确认的验证”预览功能发布，不能据此作独立认证声明。

FADGI 官方提供 35 毫米、120 和 4×5 负片目标及参考数据，适合在取得适用许可后作为受控测试的来源：<https://stage.digitizationguidelines.gov/guidelines/digitize-OpenDice.html>。该页面未在下载处声明可再分发许可，因此本仓库不复制其目标或参考数据。
